# 作业4：多模态商品识别实测报告

刘嘉略 · 0120251050 · 2026-10-20

## 实现与环境

Vue 3、Element Plus、Express、MongoDB；百炼兼容接口，视觉模型qwen3-vl-plus，temperature=0.2。课程示例旧模型名以自己控制台实际可用模型替代。密钥只存server/.env且被Git忽略，.env.example只给变量和公开示例值。账户已为本次视觉模型开启免费额度用完即停。

统一llmClient使用后端环境变量发送请求，返回content、model、purpose与供应商usage；未知Token为null。请求超时、上游鉴权及格式异常均给可读且不含密钥的错误。

识图读取前三张本地图片，Sharp缩放后转JPEG Base64。模型只负责三个字符串数组；后端容错处理围栏和附加说明，再严格校验字段、类型、数量、长度与重复条目。只有格式失败重试一次，鉴权、额度或网络失败不自动重试。

POST /api/products/:id/analyze将合法结果与后端生成的时间、草稿状态、版本写回Product.aiAnalysis。同商品并发返回409，失败保留旧数据。前端逐商品loading、禁用防重、错误提示与蓝/绿/橙三类标签已完成。

## 真实页面与持久化

通过页面点击识图，接口HTTP200、code=0。实际返回外观5条、卖点3条、场景3条；重新载入页面后仍能从数据库读到同一结果。本次以HTTP重新读取持久化结果验证，没有声称完成Compass人工截图检查。

卖点原文：“倾斜角度便于观看屏幕”“底座提供稳定放置基础”“简洁造型适配多种桌面环境”。前端保持草稿提示，未经人工确认不能直接当作真实性能承诺。示例图片为插画演示资产，不是商家实拍。

## 验证与限制

- 8项视觉单元测试与上传集成回归合计24个测试通过；Vue生产构建通过。普通测试不消耗模型额度。
- 浏览器实测：真实HTTP200、loading/禁用按钮、并发409、网络失败恢复、三类标签、刷新持久化、非法ID400与不存在商品404、390px无横向溢出，未发现页面运行时错误。
- 代码截图直接从实际工程文件生成源码视图，不包含.env或密钥；页面截图来自真实本机运行页面。
- 当前防重复锁限于单个Node进程；多实例部署须改用共享锁或任务队列，后续部署阶段处理。
- 本次不实现文案、生图或成本看板；使用单一示例检验流程，不承诺识图正确率。
