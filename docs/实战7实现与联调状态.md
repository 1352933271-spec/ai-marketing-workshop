## 实现

1. imagePromptService：LLM按主体、海外场景、光影、构图、镜头、商业风格扩写英文；严格60-110词、最多800字符，非法最多改写一次。规则要求不从商品名称猜材质、折叠或功能，成功时打印真实[image-prompt]日志。图片仅为场景概念，不能保证商品结构与原图一致。
2. imageService：派生同地域/api/v1，调用万相异步text2image/image-synthesis，X-DashScope-Async:enable，1024*1024、n=1。查询/tasks/:taskId；官方OSS链接下载到本地，限制HTTPS官方域名、禁重定向、15MB、真实图像解码与PNG重编码，以UUID保存。
3. imageController：先预览提示词并保存记录，用户确认后才原子转换为submitting并下发任务，防止同一预览重复下单。保存taskId后轮询；每个asset并发查询共用一次更新，避免重复下载。处理PENDING/RUNNING/SUCCEEDED/FAILED/CANCELED/UNKNOWN，5分钟超时及持久化错误原因。失败后不会把上游原始报错或Key转发。
4. SceneStudio：商品分页、三场景选择、英文预览、确认生成、骨架屏；串行约3秒轮询、2分钟停止等待，可在任务历史继续查看。页面销毁清定时器及失效回调，不取消已提交的供应商任务。图片完成后可预览本地图片与查看提示词。
5. MarketingAsset增加scene、sceneIndex、imageStage、failureReason、submittedAt，原有status及taskId保留。静态目录仅额外放行generated/UUID.png等受限路径。

## 接口

- POST /api/images/preview：{productId,sceneIndex:0..2}，返回{previewId,prompt,scene}。无图建议/非法参数400，商品不存在404，扩写中409，LLM失败502。
- POST /api/images/generate：{previewId}，HTTP202返回{assetId,prompt,scene}；同预览重复提交409。先看提示词再确认，避免直接产生图片费用。
- GET /api/images/tasks/:assetId：返回{status,stage,imageUrl,message,prompt,scene}。非法ID400、非图片或不存在404；上游异常502，可继续查询；failed错误原因持久化。
- GET /api/assets?type=image：沿用实战6，用于图片及任务历史。
