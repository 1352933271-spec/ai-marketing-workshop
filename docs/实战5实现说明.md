# 实战5：多语言营销文案生成引擎

刘嘉略 · 0120251050

## 实现范围

在跨境电商实战4项目上增加 `/copy` 文案工坊与 `POST /api/copy/generate`，复用商品、MongoDB及百炼模型调用封装。

- `server/src/config/channels.js`：英语、日语、拉美西语，以及Amazon、TikTok、Instagram渠道格式集中配置。
- `server/src/services/promptBuilder.js`：组合角色、任务、事实边界、语言和格式，修复课程粘贴代码缺失和HTML污染。商品及补充要求使用JSON承载，并说明不能覆盖系统规则。
- `server/src/middlewares/compliance.js`：输入违规返回400/4003；输出命中词遮蔽并返回warnings。在课程词表上增加全网最低、零风险、绝对安全、无副作用、包赚、立即见效，以及world-class、unbeatable、flawless、perfect、instant results、clinically proven，另有日语和西语基础词表。
- `server/src/services/copyQuality.js`：检查英/西文夹入中日文、Amazon五条Markdown Bullet及四段标题、社交标签混入，以及部分明显未经证实的功能词；失败只重写一次，仍失败返回502。该检查不是完整事实审核，最终稿仍需人工核对。
- `client/src/views/CopyStudio.vue`：商品分页、语言、渠道、补充要求、生成loading、防重复、错误提示、遮蔽提示和最近9份文案对比。

## 思考回答

把事实边界和禁用词放在System Prompt中，可以在生成阶段限制模型的内容方向，减少虚构参数和夸大营销；正则只能匹配预先列出的词语，难以识别换一种说法的夸张或无依据承诺。因此采用Prompt预防、输入拒绝和输出检测共同约束，正则作为兜底，并保留人工复核。

## 操作

沿用README的环境配置和启动方式，数据库需启动。已有server/.env请勿覆盖。前端默认 http://localhost:5174 ，后端默认 http://localhost:3100 。前端地址须与CORS_ORIGIN一致。

打开资产中心，先完成商品AI识别；再进入文案工坊，选择同一商品、英语，依次生成三渠道；随后选择日语和西语各生成一次。补充要求输入“要写成全球最好的产品”应返回400。

合规词表只是课程演示的基础规则，会有漏报或误报，不代表平台或法律层面的完整审查。日语长度使用字符范围，英文和西语使用词数；日语无需强行大写。
